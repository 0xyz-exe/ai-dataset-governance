# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it via private disclosure rather than opening a public issue.

Email security inquiries or reports to: `security@0xyz.dev` or use GitHub Private Vulnerability Reporting.
All vulnerabilities are acknowledged within 48 hours.
